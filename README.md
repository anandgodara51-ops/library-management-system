# 📚 Library Management System

## 🔹 Overview
This is a Python-based Library Management System with GUI support. It allows efficient management of books, users, and transactions.

## 🔹 Features
-  User Authentication (Admin & Student)
-  Add / View Books
-  Issue Books
-  Return Books
-  Fine Calculation (late return)
-  Analytics Dashboard (Most Read Books)

## 🔹 Tech Stack
- Python
- Tkinter (GUI)
- SQLite / MySQL
- Matplotlib
- 
Run:
python LMS/LIBRARY_M_S_project.py
